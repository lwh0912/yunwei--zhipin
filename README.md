# 云味智拼 YunWeiZhiPin

> 云南咖啡多模态风味认知与智能拼配系统

面向云南咖啡产业"风味数据难统一、品质评价依赖经验、拼配研发周期长、风味稳定性不足"四大痛点，构建「多模态风味数据采集 → 品质预测 → 目标风味反向设计 → 智能拼配 → 生产反馈」一体化人工智能系统。

**本仓库用途**：参赛作品「研究现状/背景」章节的综述写作过程留痕 + 算法实现 + 数据来源登记（导师要求"先综述、记得写 repo"）。

## 技术主线（综述骨架的装载对象）

多模态风味数据 → 品质预测 → 目标风味反向设计 → 智能拼配 → 生产反馈

## 四个产业痛点（综述"研究现状与不足"的落点）

1. 风味数据难统一
2. 品质评价依赖经验
3. 拼配研发周期长
4. 产品风味稳定性不足
