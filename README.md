## 技术主线（综述骨架的装载对象）

多模态风味数据 → 品质预测 → 目标风味反向设计 → 智能拼配 → 生产反馈

## 四个产业痛点（综述"研究现状与不足"的落点）

1. 风味数据难统一
2. 品质评价依赖经验
3. 拼配研发周期长
4. 产品风味稳定性不足
